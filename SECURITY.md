# Seguridad

Comunica vulnerabilidades de forma privada a los mantenedores; no incluyas datos sensibles en issues. Se mantienen límites de descarga/body/batch, validación de offsets y hashes, temporales atómicos, contenedores no root y permisos mínimos. Amenazas principales: fuente comprometida, artefacto truncado, desbordamientos, path traversal, JSON abusivo y agotamiento de recursos.
