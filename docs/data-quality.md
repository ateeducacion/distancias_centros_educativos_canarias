# Calidad y privacidad

El pipeline rechaza cambios de esquema, UTF-8 inválido, duplicados, códigos o coordenadas inválidos y no descarta filas silenciosamente. El umbral inicial de ajuste (250 m de aviso, 2 km de fallo) es una política conservadora revisable del proyecto, no una propiedad universal. Las coordenadas oficiales permanecen públicas; las ajustadas solo se auditan y enrutan.
