# Limitaciones

Sin tráfico, incidencias, horarios ni restricciones temporales. Perfil inicial solo automóvil. La distancia pertenece a la ruta más rápida seleccionada. Solo misma isla. Coordenadas y red dependen de las fuentes; la duración no predice tráfico; ruta no disponible no implica acceso físico imposible; puede haber desfase entre actualizaciones.
