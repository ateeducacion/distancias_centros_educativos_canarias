# Demo

La demo forma parte de la portada de la documentación y usa la copia verificada de la última release `data-*` publicada en `data/latest/`.

[Ir a la demo de distancias](index.md){ .md-button .md-button--primary }

Al seleccionar origen y destino, el navegador consulta `canarias-distances.dat` de forma local mediante un Web Worker. No hay botón de cálculo ni petición remota por cada cambio.

Para reutilizar los lectores en otra aplicación, consulta las guías de [Python](python.md), [JavaScript](javascript.md), [PHP](php.md) y [WordPress](wordpress.md).
