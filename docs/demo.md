# Demo

La demo forma parte de la portada de la documentación y usa exactamente los artefactos generados desde `main`.

[Ir a la demo de distancias](index.md#consultar-distancia){ .md-button .md-button--primary }

Al seleccionar origen y destino, el navegador consulta `canarias-distances.dat` de forma local mediante un Web Worker. No hay botón de cálculo ni petición remota por cada cambio.

Para reutilizar el mismo mecanismo en otra aplicación, consulta las guías de [JavaScript](javascript.md) y [PHP](php.md).
