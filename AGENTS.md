# AI contributor instructions

- Write code, identifiers, comments and docstrings in English; write user documentation in Spanish.
- Never change CEDIST01 without incrementing its version. Never edit generated data manually.
- Never invent benchmarks, dates, hashes, sizes or counts. Never alter official center codes or classify entities by odd/even codes.
- Run `make ci` before declaring work complete and report unavailable tooling exactly.
- Do not publish, comment, push, open pull requests or modify remote resources without explicit authorization.
- Preserve Ubuntu Server and macOS/Homebrew compatibility. Prefer Alpine containers where viable and `vim` in terminal editing examples.
- Keep scripts POSIX `sh` unless Bash is documented. Treat code versions and data versions separately.
